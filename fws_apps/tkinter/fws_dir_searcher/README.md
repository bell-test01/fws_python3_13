# fws_dir_searcher

## 概要 (Summary)
指定したルートディレクトリ以下から、キーワードに部分一致するディレクトリを高速に検索するGUIアプリケーションです。
Tkinterを使用して構築されています。

## 主な機能 (Features)
* **ディレクトリ検索**: 指定したルートディレクトリ以下を再帰的に走査し、検索キーワードに部分一致する名前を持つディレクトリを検索します（大文字小文字の区別なし）。
* **ファイル情報の取得**: 検索にヒットしたディレクトリの直下にあるファイルの詳細情報（ファイル名、拡張子、サイズ、更新日時など）を取得して表示します。

## 起動方法 (How to run)
エントリーポイントである以下のファイルを実行してアプリケーションを起動します。
```bash
python fws_dir_searcher.pyw
```
（または `fws_dir_searcher.pyw` をダブルクリックして実行します）
